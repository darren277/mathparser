📘 Algebra Compass

⚖️ Core Idea

An equation is a balance scale. Whatever you do to one side, you must do to the other:

x + 3 = 10 → x = 10 - 3 → x = 7

🧰 Toolbox

🔁 Solving Flow

  1. Distribute (if needed)
  2. Combine like terms
  3. Move variables to one side, constants to the other
  4. Isolate the variable
  5. Check your answer (plug it in!)

🧠 Undo the Layers (Mental Metaphor)

Solving is like peeling an onion 🧅. Strip away layers:

  • Addition/Subtraction → Undo with opposite
  • Multiplication → Undo with division
  • Exponents → Undo with roots or logs (advanced)

📐 Trigonometry Basics

SOH-CAH-TOA is your mnemonic:

  • Sine = Opposite / Hypotenuse
  • Cosine = Adjacent / Hypotenuse
  • Tangent = Opposite / Adjacent

Reciprocal Functions

  • Cosecant (csc) = 1/sin
  • Secant (sec) = 1/cos
  • Cotangent (cot) = 1/tan

Key Identities

  • sin2(θ) + cos2(θ) = 1
  • 1 + tan2(θ) = sec2(θ)
  • 1 + cot2(θ) = csc2(θ)

Functions

Function: A rule that assigns one output to each input

Example: f(x) = 2x + 3

Domain: All allowed `x`-values (inputs)

Range: All possible `y`-values (outputs)

Independent variable: Usually `x`

Dependent variable: Usually `y = f(x)`

More on Functions

A function is a relation that assigns exactly one output for each input. The domain is the set of all possible inputs, while the range is the set of all possible outputs.

Transformations

Transformations change the graph of a function without changing its basic shape. Here are some common transformations:

✨ Big Picture

Algebra is structured reasoning about unknowns.

It’s the logic of fair transformations, where every move preserves truth. Think of yourself as a symbolic detective 🕵️‍♀️ tracing the steps back to the mystery variable.
